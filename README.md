# Anharmonic Studio

Anharmonic Studio is a desktop music production environment centered on sampling, arrangement, beatmaking, recording, and fast hands-on editing.

## Audio clip workflow

Arrangement audio clips support a right-click **Tempo & stretch** workflow with exact 1, 2, 4, 8, and 16 bar fitting, custom bar lengths, and automatic source-tempo matching when BPM metadata or a `### BPM` filename tag is available. The current fitting mode is **Resample**, so time and pitch move together. Fitted clips are rendered as new library derivatives while the original source is retained.

Additional clip utilities include **Make audio unique**, **Use full source**, nondestructive **Normalize peak**, gain reset, trimming, splitting, reverse, looping, Autotune handoff, sample-note writing, and WAV export.
