FORMATS
SVG: genuine scalable paths, including outlined logo lettering. No fonts required.
PNG in 01-Logos and 02-Symbols: transparent RGBA, with clean antialiased edges.
App and social images intentionally include their backgrounds.
ICO: multiple sizes in one Windows/browser file.
ICNS: macOS icon resources through 1024 px.
PDF: vector identity guide. All color specifications are sRGB.

COLOR VARIANTS
ink: #111315 artwork, for light backgrounds.
black: #000000, for one-color black production.
white: #FFFFFF, for dark backgrounds.
accent-on-light: #427BFF symbol with ink lettering.
accent-on-dark: #427BFF symbol with white lettering.
currentcolor: standalone SVG inherits CSS color when embedded inline.

SIZES AND USE
Primary logo PNGs are 3000 px wide; wordmarks are 2400 px; symbols are 2048 px.
Use SVG when larger output is required. Ordinary logo and icon exports are under 1 MB.
Use favicon-16.png / favicon-32.png for the smallest browser placements.
The channel banner keeps the main logo inside a centered 1546 x 423 px safe area.
Keep logos proportional. Preserve padding, the wave, and the separate dot.
Do not flatten a transparent white logo onto a white background.
