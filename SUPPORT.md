# Support scope

Official released binaries are Anharmonic Studio's supported distribution for musicians.
Support covers those published builds on their documented platforms. Release candidates
remain evaluation builds until release acceptance is complete. The standard $1 download
is open through the website, with private installer delivery after payment confirmation.
The packages are unsigned and the Mac builds are not Apple-notarized. Physical-device
acceptance remains unfinished.

For purchase or official-installer help, contact
[anharmoniclabs@gmail.com](mailto:anharmoniclabs@gmail.com). Include your operating
system and app version. Use email for private purchase questions; application bug
reports can still go to GitHub Issues under the guidance below.

## Installing official downloads

Windows may show an unknown-publisher or SmartScreen warning. macOS may block either
Mac build and require individual approval in Privacy & Security. Some security policies
and managed computers prevent installation entirely. Payment does not remove these
restrictions or include a signed/notarized build. Linux users must extract the full
archive and have compatible system libraries, graphics, and audio drivers.

Read the [installation guidance before purchasing](https://anharmoniclabs.github.io/AnharmonicStudio/#installation-guidance).
It links to Apple and Microsoft guidance and explains the difference between an
unrecognized-publisher warning and a malware or damaged-file alert. Keep antivirus
and system-wide security protections enabled. The download-page checksums verify
file integrity; they do not certify software safety.

## Self-compiled copies

Building from source is intended for developers. We do not provide installation,
compiler/dependency setup, or configuration troubleshooting for self-compiled builds.
Those builds do not include a signed official installer or managed updates. Developers
are responsible for their environment and hardware validation; arbitrary machine and
driver combinations are not guaranteed.

The complete source and compilation/installation scripts remain available. This support
scope does not change anyone's GPL rights or restrict building, modification, or sharing.
The [developer build guide](BUILDING.md) covers all supported build targets.

## Application bugs and contributions

Reproducible application bug reports and patches are welcome from everyone, including
source users. Use [GitHub Issues](https://github.com/Anharmoniclabs/AnharmonicStudio/issues)
for application bugs, with the version/commit, OS and architecture, installation method,
reproduction steps, and relevant audio-device/sample-rate/buffer details. For a source
build, distinguish an application defect from local toolchain or dependency problems.

Share a minimal example using disposable audio. Do not post private recordings, payment
information, credentials, or private keys. See [CONTRIBUTING.md](CONTRIBUTING.md) for
code contributions. No response-time guarantee or paid support tier is announced.
